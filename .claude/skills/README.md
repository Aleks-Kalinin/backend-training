This directory contains repo-specific skills for Claude to follow while working in this codebase.

- `backend-author.md` — NestJS module/service/controller implementation
- `api-contract.md` — REST API versioning, Swagger, and route design
- `database-orm.md` — TypeORM/Postgres data access and migrations
- `test-engineer.md` — Jest and e2e validation workflows
- `security-audit.md` — auth, validation, cookies, and request safety checks
- `devops-local.md` — local startup, env config, and container setup

Use the most relevant skill for the task. Each skill is intentionally focused and should guide the agent toward consistent repo conventions.
